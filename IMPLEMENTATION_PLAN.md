# План реалізації UART-радіомосту ES900TX ↔ ES900RX

Мета: прозорий двобічний потік UART-байтів без залежності від MAVLink, CRSF або RC-каналів, із підтвердженням доставки, керуванням потоком і FHSS. Цільові плати: HappyModel ES900TX / ESP32 / SX1276 та ES900RX / ESP8285 / SX1276 (підтримувані конфігурації: штатна пара ES900TX ↔ ES900RX, компактна пара 2× ES900RX для 10–15 м та далекобійна високопотужна пара 2× ES900TX до 1000 мВт).

## Як працювати зі списком

- На початку роботи назвати ID обраних пунктів. Працювати в межах дорученого обсягу.
- `- [ ]` означає невиконане завдання; `- [x]` — реалізоване й перевірене. Частково виконані або заблоковані пункти залишати без позначки виконання, із поясненням у журналі.
- Позначати пункт виконаним лише після імплементації та відповідних перевірок за `AGENTS.md`. Самої підготовки коду чи успішної компіляції недостатньо для завдань, які потребують стендових вимірювань.

Пункти з апаратними критеріями залишаються відкритими до завершальних вимірювань; для змішаних пунктів окремо фіксувати готовність коду та неперевірену на платах частину. Програмні залежності залишаються обов'язковими; незалежні завдання можна виконувати в іншому порядку в межах доручення.

## Вихідний стан і технічні передумови

- У поточному AirPort байти вилучаються з черги до підтвердження доставки; черги мають 64 байти, спільний приймальний радіобуфер — 16 байтів.
- Поточний `SX127xDriver` реалізує LoRa. Наявність DK500/K1000 в інших драйверах не означає наявності FSK для SX1276. Оптимізації LoRa BW500 з errata вже є — їх потрібно зберегти й перевірити.
- За [даташитом Semtech](https://cdn.sparkfun.com/assets/a/a/0/b/5/DS_SX1276-7-8-9_W_APP_V5.pdf), штатна межа FSK — 300 кбіт/с. Початкова ціль — 250 кбіт/с; 500/1000 кбіт/с розглядаються як окремі експерименти. FIFO має 256 байтів у LoRa і 64 байти у FSK; у FSK треба врахувати також службові байти packet engine.
- Діапазон SX1276 у проекті розширено до безпечного вікна 750–1000 МГц (безпечний відступ від крайніх точок зриву PLL 730 та 1020 МГц) із 4-бендовою структурою та динамічним fallback-перемиканням при деградації чи глушінні зв'язку. На робочих відстанях 10–50 м узгодження антен на краях діапазону не лімітує зв'язок завдяки високому запасу енергетики лінку.
- Baud rate UART не дорівнює корисній радіопропускній здатності. Відсутність втрат можна вимагати для даних, прийнятих у буфери, за визначених умов навантаження й керування потоком. Скінченні RAM-буфери не забезпечують необмеженого накопичення під час розриву зв'язку або збереження даних після втрати живлення.
- Позначені нижче базові збірки є штатними FCC915-конфігураціями. Bridge-режим, розширені EML-пакети й новий FHSS ще не реалізовані.
